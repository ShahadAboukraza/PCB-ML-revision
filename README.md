# PCB Exposure Risk Modeling — Revision Analyses (ETAP-D-26-00876)

Source code for the new analyses in the revised manuscript
**"PCB Exposure Risk Modeling Using Augmentation and ML Models Across Maternal Cohorts"**,
written in response to the reviewers' comments.

The code addresses the main methodological concern raised in review. The exposure label (high vs low)
is the thresholded sum of the seven Set-B congeners, and the original models also received those same
congeners as inputs, so they were largely reconstructing the label. This code removes that leakage,
replaces the single 75/25 split with repeated cross-validation and confidence intervals, and runs the
sensitivity analyses the reviewers requested.

## Quick start

```bash
pip install -r requirements.txt
# put the cohort CSV in data/ (see data/README.md - data are not public)
SMOKE=1 ./run_all.sh     # few-minute check that everything runs (writes to results_smoke/)
./run_all.sh             # full analysis, roughly 30-45 min on one CPU core
```

Python 3.12 was used. All randomness is seeded (`SEED = 42`).

## Method summary

- **Label:** sum of PCB-138, 153, 156, 170, 180, 183, 187 (ng/L) above the 60th percentile (262.4 ng/L; 41/102 high).
- **Feature sets:** (a) full original set; (b) restricted, Set-B removed (primary); (c) maternal + lipid covariates only; (d) non-Set-B congeners only (PCB-28, 74, 99, 101, 118). PCB-52 is excluded (never detected).
- **Values < LOD:** substituted by LOD/2; other rules tested as a sensitivity analysis.
- **Models:** logistic regression (LR), elastic-net LR, random forest (300 trees), XGBoost (300 trees, depth 3), MLP (32-16).
- **Evaluation:** repeated stratified 5-fold CV; imputation and scaling fitted inside training folds only (`sklearn.Pipeline`); test folds are always real rows only.
- **Uncertainty:** 95% CIs and paired model comparisons use the Nadeau & Bengio (2003) corrected resampled t-statistic; Holm correction for multiple comparisons.
- **Augmentation:** label-aware bootstrap with Gaussian micro-noise (σ × feature SD), applied to training folds only.

## Scope

This repository covers the analyses added during revision for the real (NUGEN) cohort. The original
pipeline (MARBLES, EHF generation, TabNet, original single-split results) is in the project's main
analysis repository.
